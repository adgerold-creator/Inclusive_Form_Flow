Visible label / question Why necessary now? Required? Native control/type Submitted name/value Autocomplete/inputmode Constraint/instruction Sensitivity and minimization decision
Name Needed to identify the person requesting a workshop spot. Yes input type="text" name="attendee_name" autocomplete="name" Required. Basic identifying information only. No extra personal details are collected.
Email address Needed to send the fictional workshop confirmation and follow-up information. Yes input type="email" name="email" autocomplete="email" Required. Enter an address like name@example.com. Contact information is limited to email; phone number and mailing address are not needed.
Preferred workshop date Needed to know when the attendee would like to participate. Yes input type="date" name="workshop_date" N/A Required. Choose a date from October 1 through December 15, 2026. Only the requested workshop date is collected; no unrelated scheduling information is needed.
Sewing experience Helps the instructor understand the attendee's starting skill level. Yes select name="experience" with beginner / some-experience / intermediate values N/A Required. Choose the option that best matches current experience. Only a general skill level is requested instead of asking for detailed background information.
Morning session Allows the attendee to choose one preferred session time. Yes, as part of the session group input type="radio" name="session" value="morning" N/A Choose one session time. This only collects the scheduling preference needed for the workshop.
Afternoon session Provides the second available session choice. Yes, as part of the session group input type="radio" name="session" value="afternoon" N/A Choose one session time. This only collects the scheduling preference needed for the workshop.
I need to borrow a sewing machine Helps determine how many loaner machines need to be prepared. No input type="checkbox" name="loaner_machine" value="yes" N/A Optional. Check only if a loaner machine is needed. Only equipment needs are collected; no explanation for why a machine is needed is requested.
I need a materials kit Helps determine how many basic supply kits should be prepared. No input type="checkbox" name="materials_kit" value="yes" N/A Optional. Check if a workshop materials kit is needed. This only records whether supplies are needed and does not ask for unnecessary purchasing information.
Project choice Helps prepare the right materials and instructions for the attendee. Yes select name="project" with tote-bag / zipper-pouch / hem-sampler values N/A Required. Choose one beginner project. Only the project preference needed for workshop preparation is collected.
Questions or notes Gives the attendee a place to share an optional question related to the workshop. No textarea name="notes" N/A Optional. Maximum 240 characters. Do not include private or sensitive information. Optional and limited to 240 characters, with an instruction not to include sensitive information.
